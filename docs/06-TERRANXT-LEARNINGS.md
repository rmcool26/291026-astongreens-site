# UX decisions carried over from the Terranxt project

These were decided with the owner and apply here.
1. One primary CTA per page. Secondary actions are text links. No double-button bands.
2. Rows and tables instead of card grids. Cards only for forms.
3. Dark sections use a cursor glow ("flashlight") and page-aware whispers; light footer with a light wordmark band that glows on hover.
4. Page hero is the same on every inner page; only content changes (global code).
5. Closing CTA is per page and dark; footer is light.
6. Header is simple (about 6 items + one CTA). Menus show a one-line description.
7. Forms ask only what is needed; every form has a thank-you state; all go to Odoo.
8. No unverified numbers. Targets are labelled as targets.
9. Placeholders say what to supply and the size.
10. Process per section: audit, 3 options plus one fresh idea, owner picks, implement, move on.
11. Copy tone: short, human, no hype, English.
Difference for Astongreens: more corporate and tender-ready, serif-free but with stronger numbers and proof, green and sand palette, offices by country.
