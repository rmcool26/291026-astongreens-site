## Visual and layout
- Fonts: Manrope + Public Sans is clean but common. Suggested pairing: Archivo (headings, wider and more industrial) + Public Sans (body). Keep IBM Plex Mono for labels. Not applied: it changes line lengths everywhere, so test on all pages first.
- Palette: forest #14240f, amber #d99a2b, white. Drop the mid greens (#4b8f27, #3b7a1e) from large areas; they are what makes the site feel generic "green energy".
- Layout change made: Careers "Why Astongreens" three cards are now numbered rows.
- Layout changes recommended: Home "Where we work" tabs to a real map with the four offices; Home services list to one large project photo per service.
- Delete or hold: the logo strip on Home until real logos exist; the Technovision band "4 tools" if it feels like filler.
