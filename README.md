```
astongreens-site/

  js/main.js          header, menus, footer, glow, whispers, scroll effects, forms, booking
  assets/images|logos|videos
  docs/               sitemap, design system, content facts, audit, checklist, pages/*.md
  281026_ag_summary.md  full project summary for humans and AI
```

Edit the menu and footer in js/main.js. Edit colours in css/styles.css :root. Replace [bracketed] text and dashed placeholder boxes.
